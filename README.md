# Rac97Work

First-phase application shell for a personal operating system/workbench.

## Run locally

Open index.html in a browser or serve this folder with any static file server. Routes use hashes such as #home and #projects, so the shell works without a backend.

## Scope

This phase includes responsive navigation, light/dark themes, Search and Quick Capture placeholders, the Home information hierarchy, and placeholder routes for each planned module. Visible data is explicitly visual placeholder data; no database or AI integration is present.
